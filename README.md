# 🎬 FilmHub - React Movie App

A dynamic and responsive movie web application built with **React** and **React Bootstrap**. The application fetches live data from a movie API, allowing users to browse, search, and manage their favorite films. It supports full localization with multi-language switching (Arabic & English).

## 🚀 Live Demo
Check out the live application here: ([https://film-hub-7hu9.vercel.app](https://film-hub-7hu9-ezsj2epvy-sohyla-s-projects.vercel.app))

---

## ✨ Features

*   **Live Movie Data:** Fetches and displays real-time movies and trends directly from an external API.
*   **Authentication:** Simulated Login and Register functionality to handle user access.
*   **Favorites Management:** Users can add movies to their personal favorites list or remove them easily.
*   **Movie Details Page:** A dedicated page displaying detailed information for each movie (rating, overview, release date, etc.).
*   **Pagination:** Smooth and efficient navigation through movie lists and pages.
*   **Multi-Language Support:** Full translation between **Arabic** and **English**, handled smoothly across components.

---

## 🛠️ Tech Stack & Architecture

*   **Frontend Library:** React.js
*   **Styling & UI:** React Bootstrap & CSS
*   **State Management (Global):** Redux Toolkit (used for efficient global state handling, such as favorites management).
*   **Localization / Language Switching:** React Context API (used to manage and share language context globally).
*   **Data Fetching:** Axios / Fetch API
*   **Routing:** React Router DOM
